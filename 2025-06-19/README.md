# 🏛️ Le dilemme du code legacy : on maintient ou on réécrit ?

> **Voxxed Days Luxembourg 2025** — Mondorf-les-bains, Luxembourg · June 19, 2025

[![Video](https://img.shields.io/badge/🎥_Watch_on_YouTube-red?logo=youtube)](https://www.youtube.com/watch?v=vYRVCzblWmM)

## 📖 Overview

A comprehensive talk on legacy code management strategies. Should you maintain, refactor, or rewrite? This session walks through real-world case studies (including the Ariane 5 disaster), brownfield vs. greenfield tradeoffs, stakeholder alignment, and progressive modernization techniques. Built with [Slidev](https://sli.dev/) for an interactive, developer-friendly slide experience.
