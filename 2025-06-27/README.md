> **Sunny Tech 2025** — Montpellier, France · June 27, 2025

## 📖 Overview

The Sunny Tech edition of my legacy code talk — a deep dive into practical strategies for managing, refactoring, or rewriting legacy systems. Features real-world case studies (Ariane 5), brownfield vs. greenfield comparisons, and actionable advice for aligning dev teams with stakeholders. Built with [Slidev](https://sli.dev/) for an interactive presentation experience.

---

## 📦 What's Inside

| File / Folder | Description |

| `slides.md` | Slidev source — full interactive slide deck |
